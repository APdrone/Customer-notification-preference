# Stories

This folder separates reusable orchestration from story-specific work.

## Convention

- Create one folder per story using `stories/<story-id>/`.
- Use `stories/_template/` as the starting point for a new story.
- Track the active story in `stories/index.json`.

## Suggested naming

- `story-001-automated-documentation-sync`
- `story-002-confluence-release-notes-sync`

Each story folder contains its own stage artifacts, review history, verification notes, and PR-prep document.
