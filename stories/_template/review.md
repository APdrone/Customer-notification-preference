## Checklist

- Correctness: Does each component behave as specified in requirements?
- Security: Are secrets excluded from output? Is user input validated?
- Error handling: Are API failures, missing files, empty repositories, and missing fields handled gracefully?
- Test coverage: Do tests cover the happy path and the not-found or missing-field edge cases?
- Code clarity: Are function and type names self-explanatory? Is the logic easy to follow?
- DRY principle: Is duplicated logic identified and reduced where appropriate?
- Dependency safety: Are dependency changes safe and free from known-vulnerable versions?
